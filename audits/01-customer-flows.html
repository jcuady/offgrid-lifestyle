Bugs similar to past incidents

  • RLS + INVOKER stock lock — fixed via SECURITY DEFINER retail validate (ce73d58 / 2026080112*). Watch for any new FOR UPDATE under RLS.
  • Auth recovery wipe — fixed; retest password reset on mobile PWA after deploy.
  • Fake success UX — Events Register repeats the “looks done, wrote nothing” class of bug.
  • Payment method flags — customer sees “Coming soon” unless admin enables; easy to misread as broken checkout.

Input / error validation coverage

Covered: shipping (PSGC), retail cart qty, custom draft (cuts/materials/print/qty/sheet), files (design/sheet/proof/product image), auth credentials, contact.

Gaps: Events register has no server validation; checkout shows disabled methods as “Coming soon” rather than hiding; no client retry UX for transient edge 5xx beyond PayMongo return page.
